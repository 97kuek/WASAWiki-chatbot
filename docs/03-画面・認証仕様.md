# 画面・認証仕様

コードと画面の対応を確認するための現行仕様。設計判断の根拠は
[01-設計方針.md](01-設計方針.md)、精度の数字は [02-測定結果.md](02-測定結果.md) を参照する。

## チャット画面

- PC
  - 左側にWASA Chatのロゴ、新しいチャット、チャット履歴、利用者情報を置く
  - 右側に会話本文を置く
  - 入力欄は会話領域の下部に固定する
- ヘッダー
  - 右側にサポートサイト、WASA、通知、利用者アイコンを置く
  - 通知機能は未実装のため、通知ボタンは「通知はありません」として無効にする
  - サポート先は `VITE_SUPPORT_URL` で変更し、未設定ならWASA公式サイトを開く
- 初期表示
  - 「引き継ぎ資料を、会話で探す」と表示する
  - 説明は「部内Wikiと公式サイトを横断して回答し、参照した資料を示します。」の一文だけにする
  - 質問例は6件に絞る
- 履歴欄
  - ヘッダーのメニューボタンまたは履歴欄内の閉じるボタンで開閉する
  - 狭い画面では会話の上へ重ねて表示し、背景を押して閉じられる
- スマートフォン
  - 履歴欄を初期状態では閉じる
  - 会話本文と入力欄の幅を画面に合わせる
- 質問
  - 送信直後に右寄せの吹き出しとして表示する
  - 回答の生成中も質問を画面に残す
- 回答
  - WASAロゴの横に表示する
  - ページ選定などの進捗を回答前に表示する
  - 出典はWikiと公式サイトを区別したリンクカードで表示する
- 通信
  - 質問はPOSTのJSON本文で送る
  - 質問をURLへ入れず、一般的なアクセスログに文面を残さない
  - 回答はSSEで逐次表示する
- 入力
  - 500文字を上限とする
  - `Enter` で送信する
  - `Shift + Enter` で改行する
  - 回答生成中は二重送信を防ぐ

実装:

- `web/src/App.tsx`: 画面構造、履歴、送信、ストリーミング更新
- `web/src/styles.css`: PC / スマートフォンのレイアウトと見た目
- `web/src/api.ts`: ログイン、セッション、SSE受信

## チャット履歴

- 履歴はブラウザの `sessionStorage` に保存する
- 利用者名ごとに保存キーを分ける
- 最大30チャットまで保持する
- 最初の質問の先頭28文字を履歴タイトルにする
- 過去のチャットへ追質問すると履歴の先頭へ移動する
- 次の場合に消去する
  - 利用者が「すべて削除」を押したとき
  - ログアウトしたとき
  - タブまたはブラウザを閉じたとき
- サーバーには会話履歴を保存しない
- 非公開Wikiの回答を端末へ恒久保存しないことを優先し、`localStorage` は使わない

## MarkdownとTeX

- Markdown
  - 見出し
  - 箇条書き、番号付きリスト
  - 表
  - 引用、水平線
  - 強調、コード、HTTP / HTTPSリンク
- TeX
  - インライン: `$ ... $`、`\( ... \)`
  - ブロック: `$$ ... $$`、`\[ ... \]`
  - 複数行のブロック数式
- 安全性
  - Markdown内の生HTMLは最初にエスケープする
  - リンクはHTTP / HTTPSだけを許可する
  - KaTeXは `trust: false` とし、HTMLを生成する危険な命令を許可しない
  - コード記法の中にある `$` は数式として解釈しない

実装:

- `web/src/markdown.tsx`: Markdownの安全な変換とKaTeX描画
- `web/src/styles.css`: 本文、表、数式の表示と横スクロール

## 認証

- 入力するもの
  - 普段WASA Wikiで使う利用者名
  - 普段WASA Wikiで使うパスワード
- 認証経路
  - バックエンドがMediaWikiの `action=clientlogin` へ中継する
  - `status: PASS` の場合だけ署名付きCookieを発行する
  - BotPasswords用の `action=login` は扱わない
- パスワード
  - 保存しない
  - ログへ出さない
  - Wikiでの確認後は保持しない
  - ログイン成否にかかわらずフロントの入力欄から消す
- Cookie
  - 利用者名と有効期限だけを載せる
  - HMACで署名する
  - `HttpOnly`、`Secure`、`SameSite=None` を付ける
- ログアウト
  - Cookieを失効させる
  - 現在のタブにあるチャット履歴も消去する

## 質問回数の上限

- 既定値は利用者1人あたり1日30回
- 残り回数は左下の利用者情報にだけ「本日はあと○回」と表示する
- `DAILY_LIMIT` 環境変数で変更できる
- 日本時間の0時に日付を切り替える
- API提供元の無料枠による上限ではない
- Claudeなど従量課金APIの費用が暴走しないためのアプリ側の安全弁
- カウンタはCloud Runインスタンスのメモリ内にだけ置く
- 再起動するとカウンタは消え、複数インスタンス間でも共有しないため、厳密な利用制限ではない

実装:

- `backend/internal/wiki/auth.go`: MediaWiki認証
- `backend/internal/server/server.go`: Cookie、認証必須API、レート制限
- `web/src/App.tsx`: ログイン画面、ログアウト時の履歴消去

