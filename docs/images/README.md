# ドキュメント用の画像

READMEやdocs/から参照する画像はここへ置きます。

`architecture.svg`は公開情報だけで作ったREADME用の軽量な全体構成図です。
構成を変えるときは、編集用の`docs/diagrams/01-全体構成.drawio`も同時に更新してください。

参照するときは、リポジトリ直下からの相対パスで書いてください。

```markdown
![チャット画面](docs/images/chat-view.png)   ← README.md から
![チャット画面](images/chat-view.png)        ← docs/ の中から
```

## ⚠️ 置く前に、必ず中身を見てください

**このリポジトリは公開されていますが、引き継ぎWikiの中身は公開していません。**

チャット画面のスクリーンショットは、**回答の本文がそのまま写ります。** 撮り方に
よっては、次のようなものが公開リポジトリに載ってしまいます。

- 顧問・会長・OBなど**個人の実名**と、その人に関する内部的な運用
- 申請手順、作業場の契約、設計の数値といった**Wikiにしかない情報**
- GoogleドライブなどのURL

## 安全な撮り方

**対外説明モード**（参照範囲が公式サイトだけ）で、一般公開の情報だけを聞いた
画面を撮ってください。出典カードが「公式サイト」だけになっていれば安全です。

例:「WASAはどんなサークルですか」「歴代の機体を教えてください」

左側の履歴一覧にも過去の質問の題名が出ます。気になる場合は、新しいチャットを
作ってから撮ってください。

## 大きさ

READMEで見る分には横1,600pxもあれば十分です。スクリーンショットをそのまま置くと
数MBになるので、必要なら縮めてから置いてください。

```bash
sips -Z 1600 元画像.png --out docs/images/chat-view.png
```
