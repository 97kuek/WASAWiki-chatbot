# WASA Chat 画面仕様

画面と操作の現行仕様だけを扱う。認証・Cookie・保存先は
[07-認証・データ保護.md](07-認証・データ保護.md)、回答規則は
[05-システムプロンプト.md](05-システムプロンプト.md)と
[06-決定的ルール.md](06-決定的ルール.md)を参照する。

## チャット画面

- PC
  - 左にロゴ、新しいチャット、アシスタント、履歴、利用者情報を置く
  - 右に会話本文を置き、入力欄を下部へ固定する
  - 履歴欄は折りたためる
  - 履歴のスクロールつまみはサイドバー上で見失わない濃色にする
- 狭い画面
  - 履歴欄は初期状態で閉じる
  - 開いた履歴欄を会話の上へ重ね、背景タップでも閉じられる
  - 入力欄と通知が重ならないようにする
- 初期表示
  - 「引き継ぎ資料を、会話で探す」と表示する
  - Wikiと公式サイトを横断し、参照資料を示すことを説明する
  - 質問例を6件表示する
- 質問
  - 500文字以内とする
  - `Enter`で送信し、`Shift + Enter`で改行する
  - 送信直後から右寄せの吹き出しへ残す
  - 回答生成中の二重送信を防ぐ
- 回答
  - 回答者のアイコン・名前・回答モードを表示する
  - ページ選択、資料読込、回答生成、API待機の進捗を表示する
  - MarkdownとTeXを表示する
  - 出典はWikiと公式サイトを区別したカードにする
  - 回答はSSEで逐次表示する
  - 完了後に👍／👎を表示し、1タップで評価を保存する
  - 評価理由と補足文は任意にする

## アシスタント切り替え

- アシスタントを切り替えた場合
  - 選んだアシスタントを端末へ保存する
  - アシスタント一覧からチャット画面へ戻る
  - **既存の会話へ継ぎ足さず、新しいチャットを開く**
  - 画面上部の通知で、切り替えと新しいチャットの作成を伝える
- 同じアシスタントをもう一度選んだ場合
  - 新しいチャットを増やさず、現在のチャットへ戻る
- 回答生成中
  - 規則と参照範囲が途中で変わらないよう、切り替えを拒否する
- 理由
  - アシスタントごとに一般知識の可否、参照範囲、口調が異なる
  - 同じ履歴内で混ぜると、過去回答をどの規則で読めばよいか判別できない
  - 履歴へは各回答時の`assistantId`と`assistantName`も残し、表示上の追跡を可能にする

## アシスタント一覧・編集

- 一覧
  - 汎用を先頭に置く
  - 共有アシスタントはアイコン、名前、説明、作成者、参照範囲を表示する
  - お気に入り、名前順、作成者順で並べ替えられる
  - お気に入りと並び順だけを`localStorage`へ保存する
- 作成
  - ログイン済みの全員が作成できる
  - 名前、説明、指示、参照出所、参照区分、任意の画像を設定できる
  - 画像は位置を調整して128pxの正方形へ焼き込んでから送る
- 編集と削除
  - 作成者本人と`ADMIN_USERS`だけに表示する
  - 他人の設定は直接編集せず、複製して自分の設定として直す
- 回答上の位置づけ
  - アシスタントは別の高精度モデルではない
  - 違いは参照範囲の絞り込み、一般知識の可否、回答形式・口調である

## チャット履歴

- Wiki利用者ごとに最大30チャットをFirestoreへ保存する
- 最初の質問の先頭28文字を初期タイトルにする
- 追質問を行った履歴は先頭へ移動する
- 表示を次に分ける
  - ピン留め
  - 今日
  - 昨日
  - 過去7日間
  - `YYYY年M月`
- 各履歴で次を行える
  - ピン留め・解除
  - タイトル変更
  - 端末の共有機能またはクリップボードによる共有
  - 個別削除
- 共有前に、非公開Wikiの内容を含む可能性を確認する
- 「すべて削除」は表示しない
- 追質問では完了済みの直近2往復だけをAPIへ送り、全履歴は送らない
- アシスタント切り替えでは追質問にせず、新しい履歴を開始する

## 回答モード

- 入力欄の上に「自動・じっくり」の2択を置く
- 「高速・標準」は自動判定内部の段階であり、通常画面では選ばせない
- 選択を`localStorage`へ保存する
- 旧画面で保存された「高速・標準」は「自動」へ移行する
- 生のモデル名やthinking値を通常画面へ出さない
- 回答欄には指定モードを残す
- 自動で内部判定された高速・標準の段階は通常画面へ表示しない
- APIが受け付ける値は`auto / fast / standard / deep`だけとする
- 自動判定
  - 比較、変遷、歴代、理由などは「じっくり」
  - 型番、日付、人物の一点確認は「高速」
  - その他は「標準」
- 段階別モデルはサーバー側の許可リストから選び、ブラウザからモデルIDを指定させない

## 通知と読込表示

- 保存、削除、アシスタント切り替えなどの一時通知
  - 画面下部には出さない
  - 画面上部中央から現れ、時間経過後に上へ戻って消える
  - チャット本文と入力欄を覆わない
- 回答待ち
  - 主翼・胴体・尾翼の分かる機体が航跡を引いて旋回するアニメーションを表示する
  - 初期読込では大きな旋回表示、回答欄では小さな進捗表示として同じ意匠を使う
  - OSの`prefers-reduced-motion`が有効なら動きを抑える
- 右上メニュー
  - 改善、お知らせ、プロフィールは同時に1つだけ開く
  - 別のボタンを押した場合は、開いていた内容を閉じて押した内容へ切り替える

## フィードバック

- 右上の情報量が重複していた「WASA」表示を削除する
- 同じ位置に「改善を送る」を置く
- 説明は「匿名で管理者にフィードバックを送れます」だけを表示する
- 画面全体の報告は分類を1つ選び、明示的な「送信する」を押した時点で送信する
- 分類の選択だけでは送信しない
- 回答評価は👍／👎を押した時点で送信する
- 理由チップと500文字以内の補足は任意にする
- スマホではポップアップを画面幅へ収め、分類と送信を44px以上のタップ領域で縦に並べる
- 管理者だけが最近の報告と件数を同じ画面で確認できる
- 詳細: [08-評価・フィードバック.md](08-評価・フィードバック.md)

## アシスタント一覧の密度

- 汎用アシスタントはロボット記号ではなくWASA Chatのマークを使う
- PCではタイトル、説明、件数、並べ替え、新規作成を同じ1行へ置く
- 狭い画面では説明を省略し、並べ替えと新規作成を同じ操作行へ置く

## Markdown・TeX・リンク

- Markdown
  - 見出し、箇条書き、番号付きリスト、表、引用、水平線、強調、コード
- TeX
  - `$ ... $`、`\( ... \)`、`$$ ... $$`、`\[ ... \]`
- 安全性
  - 生HTMLをエスケープする
  - リンクはHTTP / HTTPSだけを許可する
  - KaTeXは`trust: false`とする
  - コード記法内の`$`を数式として解釈しない

## 実装対応

- `web/src/App.tsx`
  - 画面、履歴、アシスタント、通知、送信、SSE更新
- `web/src/styles.css`
  - レイアウト、レスポンシブ表示、通知と読込アニメーション
- `web/src/api.ts`
  - ログイン、セッション、履歴、アシスタント、SSE通信
- `web/src/markdown.tsx`
  - MarkdownとKaTeXの安全な表示
- `web/public/announcements.json`
  - お知らせ本文

## 確認

```bash
cd web
npm run build
```

- アシスタントを変更すると空の新規チャットへ移る
- 同じアシスタントを再選択しても履歴は増えない
- 回答中は切り替えられない
- 通知が入力欄と重ならず、上から現れて消える
- PCと狭い画面の両方で履歴・入力欄・通知が重ならない
