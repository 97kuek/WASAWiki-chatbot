# WASA Chat

> 精度検証・本番運用確認フェーズ

## 概要

WASAの内部情報を参照して、
自然言語で質問できるチャットボットです。

ChatGPTやClaudeといった生成AIとは違い、
WASA内部の情報を出典として回答を生成するため、
より正確な情報が得られます。

![チャット画面](docs/images/chat-view.png)

現在は、以下の情報に対応しており、駆動班ページや翼班ページなども追加予定です。

他に追加してほしいドキュメントなどがあれば、私に連絡ください。

- WASA wiki
- WASAのホームページ
- FEEのホームページ

また、**アシスタント機能**も搭載しており、個別にプロンプトで最適化した回答をしてくれます。

各個人がアシスタントを自由に制作することができ、公式HPから引用して広報の手助けをしてくれる「オフィシャル広報用bot」や鳥人間関係のネタツイを考えてくれる「ネタツイbot」、「しゅよっくんbot」など様々なアシスタントがデフォルトで用意されています。
